Project Title: Multimodal Deepfake Detection using Feature Fusion & XAI
Core Concept  : Combining Image, Spatial-Temporal Video, and Speech Audio Features
                before Classification for Robust Deepfake Forensics.

--------------------------------------------------------------------------------
1. EXECUTIVE SUMMARY & CORE ARCHITECTURE
--------------------------------------------------------------------------------
Instead of evaluating each modality independently and taking a simple majority vote 
between separate predictions, our system extracts high-level feature vectors 
from three pretrained, fine-tuned branch networks:

  • Image Branch  : EfficientNet-B4  --> F_image (1,792 dimensions)
  • Video Branch  : CNN-LSTM          --> F_video (256 dimensions)
  • Audio Branch  : WavLM             --> F_audio (768 dimensions)

These modality-specific feature representations are concatenated into a single 
multimodal representation vector F_combined = [F_image ; F_video ; F_audio].
A lightweight PyTorch Feature Fusion Network then learns the underlying cross-modal 
relationships to make the final authenticity prediction (REAL vs DEEPFAKE).

Full Pipeline Architecture:
Media Input --> Preprocessing --> Modality Feature Extractors --> Feature Fusion 
            --> Deepfake Classifier --> Forensic Analysis + XAI --> Forensic Report

3. TECHNICAL DETAILS OF EACH MODALITY BRANCH
--------------------------------------------------------------------------------

1. Image Branch (EfficientNet-B4):
   • Input Size : 380 x 380 pixels
   • Backbone   : EfficientNet-B4 (ImageNet pretrained via timm)
   • Strategy   : Transfer learning — backbone frozen except last blocks (blocks.5, blocks.6, conv_head).
   • Output     : Feature embedding F_image (1,792 float values).

2. Video Branch (CNN-LSTM):
   • Input      : Sequence of 16 RGB frames (224 x 224 pixels) extracted via OpenCV.
   • Backbone   : ResNet-18 (frozen spatial feature extractor) + 1-layer LSTM (hidden size 256).
   • Strategy   : Spatial features extracted per frame, then fed sequentially into LSTM to capture 
                  temporal inconsistencies across frames.
   • Output     : Feature embedding F_video (256 float values).

3. Audio Branch (WavLM):
   • Input      : Raw 16kHz mono audio waveform (4 seconds / 64,000 samples).
   • Backbone   : WavLM Base Plus (microsoft/wavlm-base-plus via HuggingFace).
   • Strategy   : Utterance-level mean-pooling over frame hidden states, last transformer layers unfrozen.
   • Output     : Feature embedding F_audio (768 float values).


--------------------------------------------------------------------------------
4. WHY FEATURE FUSION IS SUPERIOR TO SIMPLE VOTING
--------------------------------------------------------------------------------
In simple voting systems, each model produces a final decision (e.g., Image says 70% Fake, 
Video says 60% Fake, Audio says 95% Fake), and decisions are combined at the end.

Feature fusion operates earlier in the pipeline:
The fusion network receives the raw, learned feature representations BEFORE classification. 
This enables the neural network to learn cross-modal correlations. For instance, a subtle 
visual pattern combined with a specific audio anomaly may indicate high probability of 
manipulation even if neither modality alone reaches the threshold for classification.


--------------------------------------------------------------------------------
5. HANDLING FLEXIBLE INPUT SITUATIONS
--------------------------------------------------------------------------------
Our architecture naturally supports different input media combinations:
  • Image Only         : Image --> EfficientNet-B4 --> Classifier --> Result
  • Video with Audio   : Video --> CNN-LSTM \
                         Audio --> WavLM     --> Feature Fusion --> Result
  • Video without Audio: Video --> CNN-LSTM --> Classifier --> Result

6. FEASIBILITY & SCALABILITY ANALYSIS
--------------------------------------------------------------------------------
• Technical Feasibility    : High. Uses proven pretrained foundation models (EfficientNet, 
                             ResNet, WavLM) and transfer learning.
• Dataset Feasibility      : High. Uses established public benchmarks (FaceForensics++, 
                             DFDC, Celeb-DF, ASVspoof, WaveFake).
• Computational Feasibility: High. Transfer learning freezes most backbone layers, 
                             allowing fast training of lightweight heads and fusion network.
• Economic Feasibility     : High. Built entirely with open-source frameworks (PyTorch, 
                             Transformers, Timm, OpenCV, Librosa).
• Scalability              : Modular design allows seamless addition of new modalities 
                             (e.g., text, thermal, depth) without changing existing branches.
